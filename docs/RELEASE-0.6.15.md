# OmniDesk 0.6.15

日期：2026-11-03。Windows x64。正式安装包与客户端开源版本。

## 连接目录

- 直接把服务器拖到同协议的文件夹调整分组，拖到 SSH / RDP 标题移回未分组。连接账号、密码、选项保持原值。
- 提供树状目录、分组列表、平铺列表、标签分类与账号分类五种视图。
- 可在设置中独立打开地址与端口、登录账号、标签和备注显示。默认保持简洁，偏好会保存。
- 标签视图支持一台服务器出现在多个标签下；拖到标签分类添加标签并保留已有标签。

## Linux 远程文件

- 从本机拖入文件或文件夹上传到当前目录或目录行。
- 拖动远程文件或文件夹到目录行移动，或拖到上级目录按钮移回父目录。
- 从文件名旁的 ↗ 拖到本机文件夹下载，当前支持 Windows 客户端；原有拖到 SSH 终端插入路径继续可用。
- 拖入上传及移动遇到同名文件拒绝覆盖，跨会话移动会给出提示。

## Windows 文件复制

- 删除“远端已复制，尚未传输”提示和手动接收按钮。
- 在服务器复制后直接到本机文件夹粘贴：读取文件列表不传输内容，本机目标请求内容时才自动下载。
- 在服务器内部粘贴保持远端操作；本机重新复制后使用新内容。传输仍有进度与取消。
- 使用 FreeRDP 并开启剪贴板重定向。每个文件先下载到缓存再交付本机流，大文件首个内容请求可能需要等待。
