# OmniDesk 0.6.43 验证范围

2026-11-12。

- 主进程及界面 TypeScript 检查通过；生产构建与固定 RDP / 采集端资源检查通过。
- Docker 服务测试使用真实回环 SSH2 连接与 POSIX shell，执行生成的命令，但 Docker CLI 是合成夹具。覆盖列表、标签合并、本地/rootless context、权限与服务异常、远程 context 拦截、完整 ID、非强制删除、占用冲突、服务变化、重复提交、无效/截断输出、超时和断线。
- 开发构建和实际 0.6.43 解包程序均通过 14 组 Docker 界面检查：入口位置、按需读取、搜索/详情、确认和取消、键盘焦点、删除、失败与过期结果、多个 SSH 会话隔离、终端挂载稳定、深色窄窗和减少动画。
- Windows NSIS 安装包及便携版均已构建。ASAR 与 14 个构建文件一致，原生资源与许可证、更新元数据及校验通过；实际便携 EXE 使用隔离 profile 启动并渲染通过。
- 本次 Docker 验证没有连接或删除用户真实服务器上的资源。Windows 安装向导和全新系统未在本次重新安装验证。安装程序未数字签名。
- 0.6.42 的 RDP 剪贴板修复和 0.6.41 的 Windows TAP 网卡采集修复包含在此版本，原生辅助程序和 Windows 采集端摘要与已验证版本一致。

公开源码额外包含采集端独立构建所需的源码、协议和安装脚本；不公开历史开发 Git 仓库、个人配置或账号/监控服务端。安装包与更新文件在独立公开仓库发布，具体 SHA-256 以 Release 附件为准。
