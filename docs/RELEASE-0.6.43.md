# OmniDesk 0.6.43

2026-11-12。

Linux SSH 会话右侧在「文件」下面增加 Docker，支持查看、搜索和删除容器、镜像。

- 容器显示名称、镜像、状态与端口，详情显示完整 ID 和创建时间；运行中的容器需先在终端停止。
- 镜像按完整 ID 合并标签，显示大小、创建时间及详情。被引用的镜像保留 Docker 冲突提示。
- 删除前确认服务器、名称与完整 ID。操作不带强制删除和卷删除参数，提交前核对本地 socket 和 Docker 服务。
- 复用当前 SSH 连接，打开或刷新时才读取；支持已有 Docker 权限的账号和本地 rootless context。Docker 缺失、权限不足、服务不可达和远程 context 分别提示。
- 断线后清空列表并忽略迟到结果；切换工具不会重新挂载终端或登录服务器。

此版本也包含此前的 Windows 剪贴板和 TAP 网卡采集修复，以及账号切换、备份入口整理和采集端安装改进。详见 [用户指南](USER-GUIDE.md) 与 [验证记录](VALIDATION-0.6.43.md)。

客户端、原生辅助源码和采集端源码以 MIT 发布。公开安装附件为 Windows x64 安装程序、blockmap、latest.yml 和 SHA256SUMS.txt；安装程序未数字签名。
