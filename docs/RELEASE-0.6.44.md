# OmniDesk 0.6.44

2026-11-13

- 客户端源码与 Windows 安装包统一到 `jixn-hu/omnidesk`，软件检查更新和打包元数据使用同一地址。
- “设置 → 关于”和“设置 → 软件更新”新增 PC 客户端源码、后端源码与部署入口。
- 统一后端以 MIT 开源于 `jixn-hu/omnidesk-server`，包含账号、同步、共享服务器、管理后台、Go 监控模块与 Docker 部署配置。两个仓库的文档互相链接。
- 本地仅维护客户端和统一后端两个目录。客户端自带采集端源码，可独立构建。

旧安装包内的更新源无法远程修改。0.6.43 及更早版本请手动下载并安装本版，之后从新的仓库检查更新。升级前建议在“设置 → 备份”导出加密备份，结束会话并退出旧程序再安装。

Windows 安装包未数字签名。GitHub 发布安装版及校验文件，便携版保留本地。现有线上后端未因本次目录和仓库整理而重新部署。
