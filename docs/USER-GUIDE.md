# OmniDesk 用户指南

当前版本：0.6.43，2026-11-12。

## 安装与连接

从 [Windows 安装包 Release](https://github.com/jixn-hu/omnidesk-releases/releases/tag/v0.6.43) 下载安装程序，核对 SHA256SUMS.txt。安装包未签名。升级前导出加密备份并保存密码，结束会话、退出旧版后安装。

首次启动选择本机凭据保护方式。无需注册账号即可建立 SSH / RDP 连接、管理公共凭据和备份。新建服务器时选择协议，填写地址、端口、用户名及密码或私钥；首次 SSH 连接核对主机指纹，Windows 连接按提示核对证书和安全模式。

## SSH 右侧工具

- **状态**：按需读取系统状态；已绑定后台监控的节点使用其指标。
- **文件**：复用当前 SSH 连接进行 SFTP 浏览、文本编辑、上传下载等操作。
- **Docker**：位于「文件」下方。服务器需要已安装并运行 Docker，当前 SSH 账号具有访问权限。普通账号和本地 rootless context 均可使用。环境不满足时显示具体原因，可在终端处理后重新检测。
- **监控**：监控功能开启且 Linux 会话满足条件时，可查看已接入节点或安装采集端。

Docker 分为「容器」「镜像」，可搜索、刷新和展开详情。容器显示名称、镜像、运行状态、端口、创建时间和完整 ID；镜像显示标签、大小和创建时间。同一镜像 ID 的多个标签合并显示。

删除前确认弹窗中的服务器、名称和完整 ID。容器的可写层会丢失；运行中的容器需先在终端停止并刷新。删除不带强制参数，不删除卷或宿主机目录。镜像被容器或多个标签引用时按 Docker 返回的原因处理。列表读取失败时保留上次数据并禁用删除；SSH 断线后清空数据。面板仅管理当前服务器的本地 Docker，远程 context 会被拦截。

## Windows 剪贴板

内嵌 FreeRDP 支持文本与文件复制。后台标签页不会抢占前台剪贴板；复制本机新文本后会更新当前会话。文件在本机实际请求粘贴时传输。恢复连接期间暂停输入和剪贴板发送，恢复后同步当前内容。

## 账号、备份与监控

侧栏「账号」配置自建服务地址，管理多个账号及切换，也可移除本机账号记录。「设置 → 备份」统一管理本地文件和 WebDAV 备份、恢复及相关选项。

不同自建服务独立管理自己的账号和监控数据。安装采集端时核对上报服务和节点；可以批量安装或覆盖安装。默认每 60 秒采集上报一次，可按节点配置间隔。Windows 手动安装时在目标机执行界面生成的命令；命令有有效期，有效期内可重试下载，使用「生成并复制新命令」更新剪贴板。

SSH / RDP 的连通性检查仅表示端口或协议可达，不能证明账号认证成功。服务端部署与权限由管理员配置。反馈问题时请先清理日志和截图中的个人信息。
