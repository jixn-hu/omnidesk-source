# OmniDesk 用户指南

## 当前版本 0.6.15（2026-11-03）

[下载安装包](https://github.com/jixn-hu/omnidesk-releases/releases/tag/v0.6.15)：`OmniDesk-0.6.15-win-x64.exe`。客户端以 MIT 开源，源码与构建步骤见 [omnidesk-source](https://github.com/jixn-hu/omnidesk-source) 和 [构建指南](BUILDING.md)。

本版新增连接拖拽、五种目录样式、信息显示开关、SFTP 拖拽，以及 Windows 本机粘贴时按需传输。见 [更新说明](RELEASE-0.6.15.md) 与 [验证范围](VALIDATION-0.6.15.md)。先导出加密备份并保存密码，退出旧版后安装；当前安装包未数字签名，可用同页 SHA256SUMS.txt 核对。

首次启动选择本机凭据保护方式，无需注册账号。设置按功能折叠并记住展开状态；公共凭据从侧栏管理。SSH 会话只有打开右侧“状态”时才开始监控，新会话与重连默认不采样。

## 安装、升级与备份

1. 在独立公开仓库的 [GitHub Releases](https://github.com/jixn-hu/omnidesk-releases/releases/latest) 下载 `OmniDesk-0.6.5-win-x64.exe`，无需 GitHub 登录。这是带安装向导、安装目录和快捷方式的安装版；客户端与后台源码仍为私有。带 `-portable` 的本地构建为免安装版，不作为默认公开附件。
2. 已在使用旧版时，先打开「设置 → 配置备份与 WebDAV 同步」导出加密备份，妥善保存备份密码。先结束会话、退出旧版，再安装新版本；不需要先删除本机配置或公共凭据。
3. 本版未做数字签名。请从项目 Release 下载，核对 SHA-256 后再决定安装；企业策略阻止时请联系管理员，不要关闭防护或运行来源不明的重新打包版本。
4. 首次启动选择主密码保护或本机密钥保护。主密码遗失无法恢复；本机密钥依赖当前 Windows 用户环境，不能把复制程序目录当成配置备份。
5. 官方账号服务地址默认空；无需官方账号即可新建连接、使用公共凭据和加密备份。需要账号服务时自行填写管理员提供的地址。

在下载目录运行以下命令，将结果与 Release 的 `SHA256SUMS.txt` 对应行比较：

```powershell
Get-FileHash -LiteralPath '.\OmniDesk-0.6.5-win-x64.exe' -Algorithm SHA256
```

便携版指程序免安装，不等于配置随 EXE 移动。目录测试包则需要保留 `win-unpacked` 下的全部文件，不能只复制其中的 EXE。官方账号后台是独立项目，客户端升级不会替你升级服务器后台。

## 外观与字体（0.6.2 新增）

从 0.6.2 开始提供，旧的 0.6.1 安装包不包含此次改动。

- 「设置」最上方的「外观与字体」可以切换跟随系统 / 浅色 / 深色主题；跟随系统会响应系统后续变化，手动选择的主题不会被系统覆盖。
- 界面字体可以选系统默认、微软雅黑、苹方或思源黑体；字体未安装时自动使用备用字体，不下载外部字体。
- 「界面缩放 · 含字号」支持 90%、100%、110%、125%，调整文字与控件大小，不修改原生窗口尺寸。各页面均使用连接页的紧凑顶栏和标签栏，切换设置、服务器管理、SSH、RDP 不再临时显示底栏或改变可用区域。
- SSH 等宽字体、10–24 px 字号和深色 / 浅色 / 跟随主题配色分别设置，实时作用于已经打开的 SSH 标签；终端工具栏的 `− / ＋` 与设置页同步。不会断开连接、重新认证或清除终端输出。
- 外观保存在本机，重启保留，同一配置目录下的多个应用窗口同步；「恢复默认外观」只重置外观，不影响连接、公共凭据或同步设置。
- Windows 远程桌面的系统字体仍由远端 Windows 设置；界面字体选项不会修改服务器字体或系统主题。

## 管理大量连接

- 「服务器管理」显示名称、地址、账号、分组、标签、备注和连接状态 / TCP 建连延迟；端口可达不代表认证成功。
- 勾选多台后点「批量编辑」：标签可添加、移除指定、替换、清空；备注可追加（另起一行）、替换、清空；分组可移入指定分组或移出。每项默认为保持原值，清空需明确选择。一次最多 1000 台，任一配置冲突或校验失败均不保存本批修改。
- 标签以彩色胶囊显示，Enter 添加、× 删除，支持粘贴多个标签和点击已有标签建议。每台最多 100 个标签，每个最多 128 字。
- 搜索支持名称、主机、端口、账号、备注和标签；建议用分组区分用途，备注记录服务角色，不把密码写进名称或备注。
- 主机可直接填 `192.0.2.10:9101`，原样保存；实际使用附带的入口端口。没有附带端口时使用右侧服务端口，例如 SSH `22`、RDP `3389`。
- 配置不完整时显示待完善标识。相同协议和目标重复新增时提醒确认；导入时可跳过重复记录。
- 左侧服务器列表可折叠，多个 SSH / RDP 可同时打开，切换标签不需要反复建立会话。
- 「公共凭据」可复用账号、Windows 域、密码或 SSH 私钥；连接中选择相应凭据，不需要多份维护同一个密码。

## 共享服务器与 Web 管理

账号服务地址支持 HTTP 和 HTTPS。内网可在「账号与同步」中填写完整的 HTTP 地址并保存；Web 管理台位于同一地址的 `/admin/#shares`。更换地址后需重新登录。

- PC 侧栏的「共享服务器」是独立页面，提供共享目录检索、拉取到本机和「共享我的本机服务器」；「账号与同步」保留登录、企业账号绑定和个人配置备份。
- 管理员登录服务端 `/admin/#shares`，可直接创建、导入和维护全部共享服务器，包括成员发布的共享。PC 管理员点击「Web 管理共享服务器」会打开已配置服务的浏览器管理台，浏览器单独登录。
- Web 管理支持按名称、地址、账号、分组、标签、备注搜索，以及协议 / 来源筛选、分页、编辑、批量删除和批量整理标签 / 备注 / 分组。管理员直接维护的配置标为「管理员维护」，删除该维护账号时团队服务器转交给当前管理员。
- Web「导入配置」支持与 PC 相同的 Remote Desktop Organizer `.rdo` 和 XTerminal `local-store.db`，也支持 JSON / CSV（含中文表头）。每批最多 1000 台、文件不超过 8 MB，先预览并勾选后导入，重复入口自动跳过；缺少凭据的条目需补全源配置后重传，推断地址和网关连接需核对后手动勾选。XTerminal 请先解锁、保存并退出，再上传配置库；浏览器不能自动扫描本机。编辑凭据留空保留原值，密码和私钥不会在目录、编辑页或导入预览中回显。
- 用户拉取共享配置时，关联密码 / 私钥保存到本机保险箱，成为独立个人连接；已有相同入口时跳过。服务端更新或删除不修改已下载的副本。

## AI 助手（PC 本地）

1. 点击侧栏「AI 助手」，或到「设置 → AI 模型配置」填写接口地址、模型名称和可选 API Key。接口须兼容 OpenAI Chat Completions 且支持工具调用；支持 HTTPS、内网 HTTP，也可填写完整 `/chat/completions` 地址。不预设模型或服务商。
2. 使用「保存并测试」验证接口连通性。API Key 加密存入本机保险箱；已保存的 Key 不会回填到界面，留空保留，勾选清除后保存可移除。无需认证的本地接口可不填 Key。
3. 配置中的「单轮模型调用上限」默认 **200 次**，可设置为 **1–1000** 的整数；这是每次发送任务允许的模型请求数，不是消息条数。最后一次请求仅根据已有结果总结，不再调用工具。设置为 1 时仅能回复与总结，无法执行工具。任何对话仍在运行或等待确认时，请先完成或停止，再修改全局模型配置或测试接口。
4. 无需手动勾选服务器。默认可检索全部本机服务器，直接在任务中说名称、IP / 地址、分组、标签或备注即可；AI 先检索资料，再定位要查询或修改的目标。也可以让 AI 先查看全部服务器资料，再整理其中指定服务器的备注。服务器很多时会分页检索，目录总量不受手动选择的 200 台限制。检索目录只读取明文登记资料，不会自动连接所有服务器。需要限定范围时，在左侧勾选最多 200 台；此时仅能访问勾选范围。点击「使用全部服务器」恢复全量检索。修改范围或当前对话权限后，下一轮会重新开始模型上下文；页面仍保留可回看的对话记录。
5. 输入任务并发送，或按 Ctrl+Enter。AI 可管理的内容取决于当前对话权限；密码、私钥、认证方式及凭据引用不提供给模型，也不开放修改。AI 整理的是本机连接资料，从共享目录导入的连接也只更新本机副本。

| 权限模式 | 可用能力 |
| --- | --- |
| 只读权限（默认） | 检索可访问范围内的服务器资料，以及固定的 Linux / Windows 状态查询。 |
| 编辑权限 | 包含只读能力；新增本机 SSH / RDP 连接资料，修改标签、备注和分组。新增资料后，在连接编辑器中补充登录凭据。 |
| 完全权限 | 包含编辑能力；可申请删除本机连接资料，或执行自定义 SSH 命令。删除资料和每条自定义命令均需要用户单独确认。 |

默认权限在「AI 模型配置」中设置；每个对话也有独立的权限选择，任务进行中不可更改该对话权限。任意自定义 SSH 命令只在完全权限开放，包括模型自称只读的命令；固定只读查询在三种模式下均可使用。

- 对 SSH Linux 可直接查询系统版本、资源占用、磁盘、网络概况、进程名和服务状态。这些查询使用固定命令，不接受模型拼接额外命令；服务器凭据在本机 SSH 层解析，保留原有主机密钥核验。需要 VPN 时请先在本机连接。
- 对 RDP Windows 可查询系统版本、CPU / 内存、磁盘、网卡、进程和服务状态。Windows 使用远程 WMI（DCOM），需要在 Windows 客户端运行、在本机保险箱保存该连接或公共凭据的密码，并具备目标远程 WMI 权限；查询使用有效的公共凭据账号和域。目标需要允许 RPC 135 及其动态端口，RDP 3389 可连不代表管理通道可用。RDP 代理不用于 WMI；要求 VPN 的连接仍需先连接 VPN。查询不会操作远程桌面、开启服务或修改防火墙。管理通道或认证失败后本轮停止该服务器后续查询，活动记录直接显示原因。
- 自定义 SSH 命令确认卡显示目标服务器、实际登录账号、地址、完整命令和目的；单次授权五分钟失效，拒绝、超时或停止后均不执行。等待期间服务器配置或登录账号变化后，会要求重新发起任务。每条命令均需单独点击「确认执行」；取消只跳过该命令。删除本机连接有单独的「确认删除」卡片，远程机器和保险箱中的公共凭据不会随之删除。
- AI 需要确认方案或询问是否继续时，会在对话中显示「确定 / 取消」小卡片。确定后继续处理；取消或超时会结束本轮后续操作。通用确认不代替 SSH 命令或连接删除授权。

确认卡直接嵌在对话记录中，展示内容和剩余有效时间。选择后收起内容并保留「已确认 / 已取消 / 已超时 / 任务已停止」记录，可展开回看；「已确认」只表示用户作出选择，实际执行结果另行显示。等待确认时焦点移到取消按钮，也可按 Escape 取消。首次 SSH 身份核验同样在助手中显示指纹与信任按钮；其他对话的身份核验在对应标签标为「待核验」，切回后可处理。切换到助手之外的页面时，身份核验仍可使用原有弹窗。

点击「新建对话」可同时保留最多 **30 个对话**，标题取自第一条任务。各对话独立保留任务、权限、服务器选择范围、回复与确认卡；切换时输入草稿也会保留。标签显示处理中、待确认、待核验、已完成等状态，其他对话有新回复或确认时显示未读圆点。应用保持运行期间，可以切换对话或进入其他页面，AI 继续在后台处理；等待用户确认时暂停，切回该对话处理后继续。停止、清空和删除仅影响当前对话；运行中的对话需先停止再删除。

例如：「列出所有服务器，按分组整理给我看」「把 192.0.2.10 的备注改为代理池」「给环保分组的服务器添加生产标签」「先查看全部服务器资料，再把备注包含代理池的服务器加上已整理标签」。名称或描述对应多台服务器时，AI 应列出名称与地址并先询问，确认具体目标后继续。编辑权限下即可修改备注、标签、分组；单次资料修改最多 200 台，更多目标分批处理。Linux / Windows 查询输出会发送给配置的模型，已知连接凭据与常见密码/令牌/私钥文本会脱敏；请勿主动在对话、备注或命令中填写敏感内容。命令最长运行 30 秒，每个输出流最多 32 KiB，超出会标注截断。

AI 回复支持 Markdown 标题、加粗、列表、表格、引用和代码块，长代码与表格在各自区域内横向滚动。连续查询默认收进「执行记录」，显示只读查询次数和记录总数；处理中仍可看到当前进度，展开可查看每条命令与输出，失败原因独立显示。回复右上角「复制」会复制完整原文，保留 Markdown 格式。回复中的 HTTP/HTTPS 链接交给系统浏览器打开。

「停止任务」会取消当前对话等待中的授权与本轮请求，并关闭该助手任务专用的 SSH 会话或 Windows 查询进程；已执行命令不会回滚，已打开的终端不受影响。对话记录使用本机保险箱密钥加密保存到数据目录 `ai-conversations.enc`，重启并解锁后可继续查看。退出或锁定客户端会停止任务；重启时未完成任务标为「已中断」，未处理的确认标为停止，不会自动重试请求或命令。输入框中尚未发送的草稿只在当前页面内存中保留。较长对话会收缩发送给模型的旧上下文，以限制单次请求大小；可回看的对话最多保留 1200 条消息。

## SSH 命令行与右侧状态

连接后，右侧有「状态 / 文件」两个按钮。登录前「状态」不可用；登录成功后自行点击才开始采样，不再随大窗口或旧版偏好自动展开。新会话与重新连接都需要再次点击。再次点击当前按钮或点击面板折叠按钮可扩大终端，文件面板仍记住本机的展开选择。

- 状态显示 CPU、内存、磁盘、网卡速率、CPU 趋势及系统详情，部分分组可单独折叠。
- 状态采集复用当前 SSH 连接，每 5 秒一次；折叠、切到文件、切换会话或隐藏窗口时暂停，不为监控额外登录。
- 服务器管理只保留端口可达状态与 TCP 延迟，不再有「监控」操作。独立监控只能从已连接 SSH 手动打开，断开即停止采样，不自动检测端口或改用其他会话。
- 「SSH 响应」是采集命令往返时间，不是 ICMP Ping；首次网速需要等待下一次采样。
- 状态采集异常不会关闭命令行。Linux 需要 `sh` 和可写的 `~/.omnidesk/`；某些受限账号可能无法读取系统统计。
- 工具栏支持搜索、复制粘贴、字号、清屏和重新连接。清屏只清本地显示；重新连接会建立新会话，不是刷新网页。

## 远程文件管理

右侧文件面板与当前 SSH 共用会话，也可以通过面板标题处按钮独立打开文件标签页。折叠或在状态 / 文件间切换后保留当前目录；重连会重新绑定 SSH 会话。

| 操作 | 使用方法 |
| --- | --- |
| 进入目录 | 双击目录，或在上方输入路径并回车 |
| 新建文件 / 文件夹 | 点击顶部按钮，或右键列表空白处选择新建，再输入名称保存 |
| 编辑文件 | 双击文本文件，或右键「编辑文件」；也可选中文件后点击底部「编辑」 |
| 保存 | 编辑器中点击「保存文件」或按 `Ctrl+S`；关闭未保存内容时会提醒 |
| 重命名 | 右键「重命名」或选中文件后按 `F2`，文件夹也支持 |
| 删除 | 右键或按 `Delete`，确认后删除；目录必须为空，不递归删除 |
| 上传 / 下载 | 使用顶部上传按钮或右键菜单；下载文件前选择本机保存位置 |
| 复制路径 | 在文件或文件夹的右键菜单选择「复制路径」 |

编辑器支持不超过 **2 MB 的 UTF-8 文本**，保留 UTF-8 BOM 和文件的 CRLF 换行方式。二进制、其他编码或更大的文件请下载后用合适的编辑器处理。新建不会截断同名文件；保存前会检查远端内容是否已变化，若冲突或权限不足，保留当前修改并显示错误。请另行保留需要合并的内容再重新打开文件；这不是服务器端文件锁或版本管理。

### 拖拽上传、移动与下载

- 将本机文件或文件夹拖到远程文件列表空白处或目录行，上传到当前目录或指定目录；同名文件会拒绝覆盖。
- 将远程文件或文件夹拖到另一个目录行移动；拖到「上级目录」按钮移回父目录，跨会话移动会被拒绝。
- 从文件名旁的 **↗** 按住拖到本机资源管理器目录，松开后按需下载；文件夹也支持。此拖出方式当前用于 Windows 客户端。

### 把路径拖入命令行

从右侧远程文件列表拖动文件或文件夹，放到**同一 SSH 会话**的命令行即可插入远程绝对路径。空格、单引号、中文及 Shell 特殊字符自动转义，不追加回车、不自动执行。

例如输入 `cd` 加一个空格，再把目录拖入终端，检查路径后自行按回车。文件也可作为 `cat`、`tail` 等命令的参数，但命令是否合适由用户决定。

跨服务器 / 跨会话路径、控制字符会被拒绝。拖到终端用于插入路径；拖到远程文件列表用于上传或移动。

## 连接目录样式与整理

进入 **设置 → 外观与字体 → 连接目录样式**，可选择树状目录、分组列表、平铺列表、标签分类或账号分类，并按需显示地址、登录账号、标签与备注。

把服务器拖到同协议的文件夹可以移动分组；拖到 SSH / RDP 标题移回「未分组」。在标签分类里拖到一个标签，添加该标签并保留其他标签。一台服务器可出现在多个标签下，它们指向同一份连接。账号分类用于查看，不会通过拖拽修改登录账号。

## Windows 远程桌面

Windows x64 内置 RDP 默认使用 FreeRDP，仍保留「用系统远程桌面打开」入口；可按连接选择流畅、均衡、清晰三档显示模式。

- 正常服务器使用 TLS / NLA。只有安全协商明确表明目标只支持旧 RDP 安全层时，才会提示是否切换兼容模式；必须本人同意后才保存该连接设置并重连。
- 账号错误、证书错误、网络异常或运行中断不会触发静默降级；不会修改服务器策略或要求关闭 NLA。旧版安全层不使用 TLS / NLA，只应对已确认可信且确实需要的目标启用。
- 如果关闭忽略证书错误，请仔细核对服务器指纹再信任；证书变化应先向管理员核实。忽略证书错误不能解决账号错误或安全层不兼容。
- 鼠标支持左 / 中 / 右键与后退 / 前进侧键，可同时按住多个按钮。支持横向、纵向滚轮和触控板细小滚动；快速滚动拆分发送，不再被单个协议事件截断。侧键只操作远端，不让本机应用退回上一页；失焦、取消或断开时释放按键。
- 点击远程画面后，`Ctrl+Shift+N` 等组合键优先发送远端，不打开本机新增连接或搜索。浏览器后退 / 前进键和 `PrintScreen` 在本机系统将事件交给应用时也可转发。要使用 OmniDesk 自身快捷键，先点击侧栏或其他非远程区域。
- `Alt+Tab`、`Win+L`、`Ctrl+Alt+Delete` 等本机操作系统保留组合可能在到达应用前被截获；不安装全局键盘钩子，也不宣称可以转发所有系统快捷键。服务器若不支持 RDP 扩展鼠标或横向滚轮，相应事件会忽略但不应断开会话；鼠标厂商自定义宏仍取决于本机驱动。
- 复制本机文字后切回远程窗口，使用 `Ctrl+V`；复制文件 / 文件夹后也可在远端用 `Ctrl+V` 或工具栏粘贴。需保持「剪贴板重定向」开启并重新连接使配置生效。
- `Ctrl+Shift+V` 会先准备剪贴板，再把带 Shift 的粘贴组合发送远端；是否粘贴为纯文本由远端应用决定。`Shift+Insert` 仍可粘贴，准备较慢也不会留下修饰键卡住。
- 远端复制文件 / 文件夹后，直接到本机文件夹按 `Ctrl+V` 或使用「粘贴」，自动按需下载，无需再点接收。复制时只读取文件列表；服务器内部粘贴不下载文件。本机实际粘贴过程中显示进度并可取消；会话断开后，尚未读取的远端文件需要重连并重新复制。剪贴板操作从当前活动且聚焦的远程桌面发起。
- 临时文件缓存为明文，复制敏感文件时注意本机环境。当前没有图片剪贴板、拖拽文件到 RDP、音频、多屏、打印机或磁盘映射；复杂域 / MFA / RD Gateway 环境请先验证，必要时使用系统客户端。

FreeRDP 的构建、协议与边界见 [详细说明](FREERDP.md)。系统客户端仍受 Windows 策略限制，软件不会绕过 MFA、强制密码提示或系统安全规则。

## 导入、备份与可选同步

- 「导入连接」支持 OmniDesk 配置、XTerminal 与 Remote Desktop Organizer；导入前检查预览，重复连接可跳过，支持的密码格式写入加密保险箱，不显示密码。
- 不保证可以破解 XTerminal 的所有加密密码；来源未提供可恢复凭据时，需要手动填写或引用公共凭据。
- 「设置 → 配置备份与 WebDAV 同步」填写备份密码后导出加密文件；可记住密码到本机保险箱，新设备仍需要该备份密码。
- WebDAV 填服务器地址、账号、密码；可选设置内调整备份目录 / 文件名，默认保存为 `OmniDesk.odbackup`。当前为手动上传、下载并导入，不是后台实时双向合并。
- 官方账号服务地址为空不影响以上功能。账号服务由管理员独立部署；共享连接是下载一份配置到本机，并非通过云端代理远程桌面。

## 更新与问题反馈

「设置 → 软件更新」默认从 `jixn-hu/omnidesk-releases` 检查公开正式 Release，并在确认后打开下载页面；无需 GitHub 登录，不会静默安装。客户端和后台源码仍为私有。0.6.1 及更早版本首次迁移需从公开仓库手动下载、安装 0.6.2 或更高版本，之后即可使用新更新源。不要把 GitHub Token 写入配置或程序代码。

反馈时请附版本、内置 / 系统客户端、错误类型、是否能建立 TCP 连接、是否运行中断；对地址、账号和文件内容脱敏，不发送密码、私钥、加密保险箱或原始连接备份。详细实测范围见 [0.6.15 验证记录](VALIDATION-0.6.15.md)。


## FreeRDP 本机通信错误

旧版「本机通信失败，请检查辅助进程运行库」表示界面没能连上本机通信通道，并不等同于远程 Windows 服务器故障或已确认缺少运行库。新版让本机通道通过受限 Node 连接直连，并在连接前实际检查辅助程序；若仍失败，记录完整错误文字和状态码以定位本机权限、缺失文件或加载器问题。请向其他电脑分发完整安装包或便携版，保留配套资源，不能只拷贝安装目录中的单个主程序 EXE。
