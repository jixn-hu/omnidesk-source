# OmniDesk 0.6.42

日期：2026-11-12。

修复 Windows 内嵌 FreeRDP 的剪贴板状态与异步竞争。

- 本机已发布新文本或文件后，忽略旧的远端文本读取响应，避免旧内容覆盖新复制；后续远端新复制仍能正常同步。
- 剪贴板通道重建时清除旧请求，恢复会话时清空旧文本缓存并取消旧文件任务，恢复后重新同步；恢复期间不把被丢弃的发送记作成功。
- 自动同步先识别本机文件及未改变的远端剪贴板，保留文件、图片、富文本和远端剪切格式；本机重新复制文字后释放旧文件状态，主进程允许新文本通过。
- 当前会话收到远端文字时，焦点在窗口工具栏也可以接收；后台标签页和失焦窗口继续隔离。

Windows 安装包和便携版包含此次原生组件更新及0.6.41的监控采集端修复。验证记录见 VALIDATION-0.6.42.md。
